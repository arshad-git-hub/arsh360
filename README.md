# Arsh360

Arsh360 is a personal life archive for stories, family, friends, education, books, dates, travel, digital links, photos, goals, and notes.

## Run locally

```bash
npm install
npm start
```

Create a production build with `npm run build`. Run `npm test` to start the CRA test runner.

Run `npm run format` to format the main JSX and CSS files.

## Your archive

The site currently uses sample content defined in `src/App.jsx`. Replace the `demoArchive` object there with your own details. The website is read-only by design; there are no forms for changing archive entries.

The app is built with Create React App, React, Tailwind CSS, React Router, and Lucide icons. Its install branding uses `public/manifest.json` and the Arsh360 icons in `public/`.
